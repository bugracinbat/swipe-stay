# SwipeStay

A Tinder-like mobile app for finding rental properties. Swipe right to save properties you like, left to pass.

## Features

- Swipe interface for browsing rental properties
- Property details view
- Saved properties list
- User authentication
- Property filtering options

## Setup

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm start
```

3. Run on iOS:

```bash
npm run ios
```

4. Run on Android:

```bash
npm run android
```

## Tech Stack

- React Native
- Expo
- TypeScript
- React Navigation
- React Native Gesture Handler
- React Native Reanimated
- React Native Paper
